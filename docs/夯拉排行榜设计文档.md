# Your Rank — 功能设计文档

> **Your Rank**：你的排行，你说了算。从凑数到神中神，每个条目都该有个说法。
> 用户可以创建任意主题的 Tier List，把条目拖入对应的品质等级行中，最终生成一张层级分布图。

---

## 一、产品概述

### 1.1 产品定位

一个以 **Tier List（层级列表）** 为核心形态的排行榜系统。五个品质等级横向铺开，每个等级是一行，条目以卡片形式分布在对应的行中。用户可以：

- 注册/登录个人账号
- 创建任意主题的 Tier List（如"2024 年度游戏"、"宝藏咖啡馆地图"等）
- 为排行榜添加条目卡片（支持上传配图）
- 将条目**拖拽到**对应的等级行中，也可在同一行内左右调整顺序
- 将完成的 Tier List 公开分享，生成层级分布图

### 1.2 核心亮点

| 特性 | 说明 |
|------|------|
| 🔐 完整账号体系 | 注册登录、邮箱验证、权限校验 |
| 🖼️ 图片上传 | 条目配图、排行封面，支持拖拽上传 |
| 🎯 拖拽入列 | 条目在五个等级行之间自由拖拽，换行即换等级 |
| 📋 多主题管理 | 每用户可创建多个 Tier List，分类管理 |
| 🔗 一键分享 | 每个排行生成唯一分享链接 |
| 🏅 五阶品质等级 | 神中神 → 凑个数，五个等级行构成一张层级分布图 |

## 二、品质等级体系

### 2.1 五个等级行

Tier List 的核心结构：自上而下五**行**，每行代表一个品质/成就等级：

```
┌──────────────────────────────────────────────────────┐
│                                                      │
│  👑 神中神                                           │
│  ┌──────┐ ┌──────┐                                   │
│  │ 条目  │ │ 条目  │    ← 天花板级，榜单的排面          │
│  └──────┘ └──────┘                                   │
│                                                      │
│  🔥 杀疯了                                           │
│  ┌──────┐ ┌──────┐ ┌──────┐                         │
│  │ 条目  │ │ 条目  │ │ 条目  │  ← 表现炸裂，碾压级       │
│  └──────┘ └──────┘ └──────┘                         │
│                                                      │
│  ⚡ 有点料                                           │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐               │
│  │ 条目  │ │ 条目  │ │ 条目  │ │ 条目  │ ← 实打实拿得出手  │
│  └──────┘ └──────┘ └──────┘ └──────┘               │
│                                                      │
│  ✓ 还行吧                                           │
│  ┌──────┐ ┌──────┐                                   │
│  │ 条目  │ │ 条目  │    ← 中规中矩，无功无过            │
│  └──────┘ └──────┘                                   │
│                                                      │
│  🫧 凑个数                                           │
│  ┌──────┐                                           │
│  │ 条目  │    ← 气氛组，缺了也不可惜                    │
│  └──────┘                                           │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 2.2 等级定义

| 等级 | 名称 | 含义 | 行色 |
|------|------|------|------|
| S | **神中神** | 天花板中的天花板，榜单的排面 | 七彩渐变 / 鎏金 |
| A | **杀疯了** | 表现炸裂，断层领先 | 赤红 / 焰橘 |
| B | **有点料** | 实打实的东西，拿得出手 | 电光紫 / 亮紫 |
| C | **还行吧** | 不功不过，中规中矩 | 石墨灰 / 灰绿 |
| D | **凑个数** | 勉强上榜，气氛组担当 | 浅灰 / 半透明 |

### 2.3 等级行的行为

- 五个等级行**始终存在**，即使某行暂时没有条目
- 空行显示为虚线占位区域，hover 时高亮提示"拖拽条目到此处"
- 条目拖入某行即自动获得该等级标签
- 同一行内的多个条目按拖拽顺序从左到右排列
- 行内条目数无上限（受单榜总条目 100 条限制）

## 三、功能模块

### 3.1 用户模块 — 注册与登录

#### 3.1.1 注册

**注册表单：**

| 字段 | 规则 |
|------|------|
| 用户名 | 2-20 字符，仅限中英文、数字、下划线，注册后不可修改 |
| 邮箱 | 必填，合法邮箱格式，不可重复注册 |
| 密码 | 8-32 字符，至少包含字母+数字 |
| 验证码 | 6 位数字，发送到注册邮箱，有效期 10 分钟 |

**注册流程：**
1. 用户填写用户名、邮箱、密码
2. 点击"发送验证码"，系统发送 6 位数字到邮箱
3. 输入验证码，点击注册
4. 验证通过后自动登录，跳转到首页

**安全约束：**
- 同一邮箱 1 小时内最多发送 3 次验证码
- 验证码错误超过 5 次，当前验证码作废，需重新获取
- 同一设备 1 小时内最多注册 3 个账号

#### 3.1.2 登录

**支持两种登录方式：**
- 邮箱 + 密码（主要方式）
- 用户名 + 密码（备选方式）

**"记住我"功能：**
- 不勾选：登录态保持 2 小时，超时需重新登录
- 勾选：登录态保持 7 天，期间无需重复登录

**安全保护：**
- 连续输错密码 5 次，账号临时锁定 15 分钟
- 在新设备登录时，向注册邮箱发送提醒通知

#### 3.1.3 用户中心

| 功能 | 说明 |
|------|------|
| 编辑资料 | 修改头像、昵称、个人简介 |
| 修改密码 | 需先验证旧密码 |
| 我的排行 | 查看和管理自己创建的全部排行榜 |
| 账号注销 | 二次确认，可选择是否一并删除排行数据 |

### 3.2 排行榜模块 — 创建与管理

#### 3.2.1 创建排行榜

**创建表单字段：**

| 字段 | 说明 |
|------|------|
| 排行榜标题 | 必填，1-100 字符 |
| 排行描述 | 选填，简要说明排行主题或评选标准 |
| 封面图片 | 选填，可本地上传或留空使用默认封面 |
| 分类标签 | 选填，可选：游戏 / 影视 / 音乐 / 美食 / 运动 / 科技 / 其他 |
| 可见范围 | 选填，默认「公开」，可设为「私密」或「仅链接可见」 |

创建成功后自动进入管理页，五个空等级行已就绪，等待添加条目。

**三种可见范围：**

| 范围 | 行为 |
|------|------|
| 公开 | 出现在发现页，可被搜索，分享链接任何人可访问 |
| 私密 | 仅创建者本人可见和管理 |
| 仅链接 | 不出现在发现页，持有分享链接的人才能查看 |

创建成功后自动生成一个 8 位分享码，通过该码可生成分享链接。

#### 3.2.2 排行榜管理

**管理列表页：**
- 以卡片网格展示"我的排行榜"，每行 3-4 张卡片
- 每张卡片展示：封面缩略图、标题、条目总数、各等级数量分布、更新时间
- 支持按分类筛选、按创建时间或更新时间排序
- 点击卡片进入管理页

**编辑排行榜：**
- 修改标题、描述、封面、分类、可见范围
- 更改可见范围立即生效
- 删除排行榜为高危操作：弹出二次确认框，明确告知"将同时删除所有条目及图片，且不可恢复"

**删除排行榜流程：**
1. 点击删除 → 弹出确认对话框
2. 用户手动输入排行榜标题以确认
3. 确认后，顺序清理：所有条目配图 → 封面图 → 条目数据 → 排行榜数据
4. 返回管理列表

#### 3.2.3 分享与发现

**分享功能：**
- 一键复制分享链接到剪贴板
- 生成分享海报：封面图 + 标题 + 完整 Tier List 截图 + 二维码
- 分享页底部展示创建者信息和"我也来创建一个"引导入口

**发现页：**
- 展示所有「公开」排行榜，默认按最近更新排序
- 支持按分类标签筛选
- 支持关键词搜索排行标题
- 滚动自动加载更多
- 每个排行卡片显示：封面、标题、条目数、等级分布概览、浏览热度

### 3.3 条目模块 — 增删改与图片上传

#### 3.3.1 添加条目

条目以**卡片**形式存在。添加时先进入「待放置区」（位于五行等级区下方），再由用户拖入目标等级行。

**添加表单：**

| 字段 | 说明 |
|------|------|
| 条目名称 | 必填，1-200 字符 |
| 描述 | 选填，补充说明 |
| 配图 | 选填，支持本地上传 |
| 外部链接 | 选填，条目详情或出处链接 |

新增条目进入**「待放置」暂存区**，由用户手动拖入对应的等级行。暂存区中的条目不显示在分享页中。

**单排行榜条目上限：** 100 条

#### 3.3.2 编辑与删除条目

- **编辑**：点击条目卡片上的编辑按钮，修改名称、描述、配图、外链
- **删除**：点击条目卡片上的删除按钮，弹出确认提示，确认后删除条目及关联图片
- **快捷删除**：将条目拖入「删除区」可直接删除（配合二次确认）
- 编辑/删除操作仅创建者可执行

#### 3.3.3 图片上传

**上传方式：**
- 点击上传按钮 → 调起系统文件选择器
- 拖拽图片文件到上传区域
- 支持粘贴剪贴板中的图片

**上传处理：**

```
选择图片
  → 本地自动压缩（限制长边不超过 1920px）
  → 可裁剪（圆形/方形两种裁切模式）
  → 显示上传进度条
  → 上传完成后即时回显
```

**上传约束：**

| 约束 | 值 |
|------|-----|
| 支持格式 | jpg、jpeg、png、gif、webp |
| 单文件上限 | 10 MB |
| 批量上传 | 最多一次 9 张 |
| 频率限制 | 每用户每分钟 20 次 |

**图片缩略图：**
- 上传后自动生成 3 个尺寸：小（200px）、中（800px）、原图
- 条目卡片用小图，详情展示用中图，点击可查看原图

**上传失败处理：**
- 网络中断 → 提示"网络异常，请检查网络后重试"
- 格式不支持 → 提示"仅支持 jpg/png/gif/webp 格式"
- 文件过大 → 提示"文件大小不能超过 10MB"
- 频率超限 → 提示"操作太频繁，请稍后再试"

### 3.4 拖拽入列模块

#### 3.4.1 交互设计

这是整个系统的核心操作区。用户将条目卡片在不同等级行之间拖拽，以改变条目所属的品质等级。

**拖拽区域布局：**

```
┌──────────────────────────────────────────┐
│                                          │
│   ┌── 👑 神中神 ───────────────────┐     │
│   │ ┌────┐ ┌────┐                 │     │
│   │ │ A  │ │ B  │                 │     │
│   │ └────┘ └────┘                 │     │
│   └────────────────────────────────┘     │
│                                          │
│   ┌── 🔥 杀疯了 ───────────────────┐     │
│   │ ┌────┐ ┌────┐ ┌────┐          │     │
│   │ │ C  │ │ D  │ │ E  │          │     │
│   │ └────┘ └────┘ └────┘          │     │
│   └────────────────────────────────┘     │
│                                          │
│   ┌── ⚡ 有点料 ───────────────────┐     │
│   │ ┌────┐ ┌────┐                 │     │
│   │ │ F  │ │ G  │                 │     │
│   │ └────┘ └────┘                 │     │
│   └────────────────────────────────┘     │
│                                          │
│   ┌── ✓ 还行吧 ───────────────────┐     │
│   │ ┌────┐                         │     │
│   │ │ H  │   ← 空行显示虚线占位     │     │
│   │ └────┘                         │     │
│   └────────────────────────────────┘     │
│                                          │
│   ┌── 🫧 凑个数 ───────────────────┐     │
│   │  (拖拽条目到此处)  ← 空行提示    │     │
│   └────────────────────────────────┘     │
│                                          │
│   ┌── 待放置 ──────────────────────┐     │
│   │ ┌────┐ ┌────┐ ┌────┐          │     │
│   │ │ 新 │ │ 新 │ │ 新 │          │     │
│   │ │条目│ │条目│ │条目│  ← 暂存区  │     │
│   │ └────┘ └────┘ └────┘          │     │
│   └────────────────────────────────┘     │
│                                          │
└──────────────────────────────────────────┘
```

**操作方式：**

| 操作 | 效果 |
|------|------|
| 从待放置区拖入等级行 | 条目获得该等级标签，进入该行 |
| 从等级行 A 拖到等级行 B | 条目等级变更，行 B 重新排列 |
| 同一行内左右拖拽 | 调整条目在该行内的展示顺序 |
| 从等级行拖回待放置区 | 条目恢复未分级状态，不展示在分享页 |
| 拖入删除区 | 删除条目（需二次确认） |

**视觉反馈：**

| 阶段 | 表现 |
|------|------|
| 抓起卡片 | 卡片微微放大 + 阴影加深，原始位置变半透明 |
| 经过等级行 | 目标行边框高亮，行内已有条目自动让出空位 |
| 悬停空行 | 虚线边框变实线，出现"释放以放入"提示 |
| 释放入行 | 卡片落入目标行，等级徽章切换，行内条目重新排布 |
| 保存中 | 底部状态栏显示"保存中..." |
| 已保存 | 切换为"✓ 已保存"，2 秒后淡出 |

#### 3.4.2 保存策略

- 拖拽释放后界面**即时响应**，不等后端
- 采用**800ms 防抖**：释放后 800ms 内无新操作则自动保存
- 防抖期间再次拖拽则重置计时器
- 保存成功后显示"✓ 已保存"
- 保存失败时恢复上次已保存的排列，提示"保存失败，请重试"

#### 3.4.3 未保存保护

- 页面关闭或跳转前，如有未保存的变更，弹出提示：
  > 「你有未保存的变更，确定离开吗？」
  > [留在页面]  /  [放弃变更并离开]

## 四、页面结构

### 4.1 页面路由与功能

| 路由 | 页面 | 需要登录 | 核心功能 |
|------|------|----------|----------|
| `/login` | 登录页 | 否 | 邮箱/用户名登录，记住我 |
| `/register` | 注册页 | 否 | 表单注册、邮箱验证 |
| `/home` | 发现页 | 否 | 浏览公开 Tier List、分类筛选、搜索 |
| `/my-rankings` | 我的排行 | 是 | 管理自己创建的全部排行榜 |

| `/s/:code` | 分享页 | 否 | 通过分享码查看 Tier List |
| `/profile` | 个人中心 | 是 | 资料编辑、密码修改 |

## 五、安全与体验设计

### 5.1 账号安全

| 措施 | 说明 |
|------|------|
| 密码加密 | 不可逆加密存储，即使数据泄露也无法还原 |
| 登录保护 | 连续失败锁定，异地登录提醒 |
| 权限隔离 | 用户只能操作自己创建的排行和条目 |
| 敏感操作 | 删除排行/注销账号需二次确认 |

### 5.2 内容安全

| 措施 | 说明 |
|------|------|
| 输入过滤 | 用户输入内容防止恶意脚本注入 |
| 图片校验 | 上传文件检查真实类型，非仅后缀名 |
| 频率限制 | 注册、上传、接口调用分级限频 |

### 5.3 体验优化

| 场景 | 策略 |
|------|------|
| 大量条目 | 等级行内支持横向滚动，保持页面整体高度可控 |
| 图片加载 | 多尺寸缩略图适配不同展示场景，懒加载 |
| 离线提示 | 网络断开时保存本地草稿，恢复后提示同步 |
| 空状态 | 空行显示引导提示"拖拽条目到此处" |
| 错误处理 | 操作失败给出明确原因和重试入口 |

## 六、后续扩展方向

5. **一键导出** — 导出 Tier List 为长图或 PDF

7. **AI 推荐** — 根据排行主题智能推荐候选条目
